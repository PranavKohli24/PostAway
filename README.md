Social Media API

Tecnologies used:- RESTful API, MongoDB, Node.js, Express.js

• Established secure user authentication with JWT for signup, login, and logout.
• Crafted CRUD operations for posts, managing captions and images while ensuring data integrity and user ownership.
• Designed a flexible comment system, enabling users to add, update, and delete comments with ownership controls.
• Framed a scalable like system to display post likes, counts, and user details efficiently.
• Added an OTP-based password reset mechanism using Nodemailer for enhanced account security
